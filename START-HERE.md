# Start here

Double-click **learn.cmd** in this folder. Press **O** to read your current lesson, then edit the file it names and save.

Your first lesson is [memory that remembers bytes](course/01-ewram/README.md). It teaches the GBA behavior and required C# on one page. Fill in the three TODOs in `Ewram.cs`; the supplied checks start failing and turn green as you implement it.

Press **N** after the checks are satisfied. The launcher remembers where you are and prepares the next starter without overwriting your work.

This same workflow covers the [whole course](course/README.md): memory, CPU, graphics, time, input, DMA, cartridges, saves, sound, debugging, and a playable game. You can ask for hints, signatures, fixtures, tests, or setup help throughout. The emulator behavior is yours to write.
