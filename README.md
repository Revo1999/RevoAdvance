# RevoAdvance

**Learn one GBA behavior → learn the C# it needs → write it.**

Double-click **learn.cmd**. It remembers your lesson and prepares the files you need.

1. Press **O** to open the current lesson: hardware, syntax, and a small coding task on one page.
2. Edit the file it names. Save to check your work.
3. Press **N** when the lesson's checks are satisfied. The next lesson uses the same workflow.

You write the emulator. Starter structure, automatic tests where supplied, and build setup are handled for you. Later visual/audio/game lessons give concrete observations to check; compiling alone does not complete them.

Start with [lesson 01: memory that remembers bytes](course/01-ewram/README.md).
