# Dma

Empty by design. You will implement programmed and active DMA channel state.

Read [hardware chapter](../../../docs/10-dma/README.md), then [Enums and named states](../../../docs/csharp-and-dotnet/enums.md), [Structs versus classes](../../../docs/csharp-and-dotnet/structs-vs-classes.md).

Use simple concrete state and operations. This project must not reference Desktop, Vulkan or physical input/audio APIs. No placeholder implementation is provided.
