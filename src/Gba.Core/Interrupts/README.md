# Interrupts

Empty by design. You will implement pending requests, masks and acknowledgement.

Read [hardware chapter](../../../docs/08-interrupts/README.md), then [Bitwise operations: a mini-course](../../../docs/csharp-and-dotnet/bitwise-operations.md), [Enums and named states](../../../docs/csharp-and-dotnet/enums.md).

Use simple concrete state and operations. This project must not reference Desktop, Vulkan or physical input/audio APIs. No placeholder implementation is provided.
