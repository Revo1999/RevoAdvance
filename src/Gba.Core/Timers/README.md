# Timers

Empty by design. You will implement counters, reloads and overflow events.

Read [hardware chapter](../../../docs/09-timers/README.md), then [Integer types, binary and hexadecimal](../../../docs/csharp-and-dotnet/integer-types.md), [Properties and fields](../../../docs/csharp-and-dotnet/properties-and-fields.md).

Use simple concrete state and operations. This project must not reference Desktop, Vulkan or physical input/audio APIs. No placeholder implementation is provided.
