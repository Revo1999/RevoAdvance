# Common

Empty by design. You will implement shared guest-time concepts only when genuinely shared; avoid a miscellaneous utility framework.

Read [hardware chapter](../../../docs/14-timing-and-scheduling/README.md), then [Integer types, binary and hexadecimal](../../../docs/csharp-and-dotnet/integer-types.md), [Performance without premature optimization](../../../docs/csharp-and-dotnet/performance.md).

Use simple concrete state and operations. This project must not reference Desktop, Vulkan or physical input/audio APIs. No placeholder implementation is provided.
