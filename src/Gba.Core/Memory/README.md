# Memory

Empty by design. You will implement physical memory storage and explicit bus access behavior.

Read [hardware chapter](../../../docs/06-bus-and-memory/README.md), then [Arrays, spans and byte order](../../../docs/csharp-and-dotnet/arrays-and-spans.md), [Integer types, binary and hexadecimal](../../../docs/csharp-and-dotnet/integer-types.md).

Use simple concrete state and operations. This project must not reference Desktop, Vulkan or physical input/audio APIs. No placeholder implementation is provided.
