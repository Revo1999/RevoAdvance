# Apu

Empty by design. You will implement sound channels, FIFOs and guest sample generation.

Read [hardware chapter](../../../docs/13-audio/README.md), then [Integer types, binary and hexadecimal](../../../docs/csharp-and-dotnet/integer-types.md), [Arrays, spans and byte order](../../../docs/csharp-and-dotnet/arrays-and-spans.md).

Use simple concrete state and operations. This project must not reference Desktop, Vulkan or physical input/audio APIs. No placeholder implementation is provided.
