# Input

Empty by design. You will implement logical keypad state and register behavior.

Read [hardware chapter](../../../docs/11-input/README.md), then [Enums and named states](../../../docs/csharp-and-dotnet/enums.md), [Bitwise operations: a mini-course](../../../docs/csharp-and-dotnet/bitwise-operations.md).

Use simple concrete state and operations. This project must not reference Desktop, Vulkan or physical input/audio APIs. No placeholder implementation is provided.
